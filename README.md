A beginner-friendly Python calculator demonstrating core programming concepts, including functions, loops, conditional statements, dictionaries, exception handling, and user input validation. Supports arithmetic operations, calculation history, and error handling.

# Python Calculator

A simple interactive calculator built using Python. This project demonstrates fundamental Python programming concepts through a menu-driven calculator.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Power (**)
- Modulo (%)
- Input validation
- Division-by-zero error handling
- Calculation history
- Interactive menu with options to continue or quit

## Python Concepts Used

This project helps beginners understand:

- **Functions:** Organizing code into reusable blocks.
- **While Loops:** Repeating the calculator menu until the user exits.
- **For Loops:** Displaying calculation history.
- **If / Elif / Else:** Handling different user choices.
- **Break and Continue:** Controlling program execution.
- **Dictionaries:** Mapping operators to their corresponding functions.
- **Try / Except:** Handling invalid user input.
- **Lists:** Storing calculation history.
- **Boolean Logic:** Validating calculations and handling errors.

## Requirements

- Python 3.x
- VS Code or any Python-compatible IDE

No external Python libraries are required.

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-calculator.git
```

2. Navigate to the project directory:

```bash
cd python-calculator
```

3. Run the calculator:

```bash
python calculator.py
```

On Windows, you can also use:

```bash
py calculator.py
```
